# Forgotten (working title: Alien Planet Roguelite)

An isometric roguelite for the browser, built with three.js and TypeScript. A solo operative descends into the layered ruins of an earlier civilisation on a hostile alien world.

This repository currently holds the design documents. Start with `CLAUDE.md`, then `docs/game_design.md` and `docs/technical_design.md`.

The game source (`src/`, `e2e/`, `tools/`) is not in this repository yet and needs adding from the local project folder.
